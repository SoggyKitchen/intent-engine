Frequently Asked Questions

Is MinIO still open source?

Yes, MinIO is still open-source but moved from Apache 2.0 to AGPLv3 in 2023. This change restricts commercial cloud providers from offering it as a service, but self-hosted use remains free.

Can Ceph run on Kubernetes?

Yes, Ceph can run on Kubernetes using Rook (https://rook.io), which automates deployment, scaling, and management of Ceph clusters in K8s environments.

Which tool is best for small teams or edge deployments?

SeaweedFS is ideal for small to mid-sized teams or edge use cases due to its simplicity, low resource footprint, and fast performance with minimal configuration.

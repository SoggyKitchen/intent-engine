Frequently Asked Questions

Can OpenClaw safely execute untrusted commands?

Not yet by default—command execution is currently unchecked, but the proposed Skill Hook system will enable automatic sandboxing and security validation before execution.

Why does Goa-VCR cause git churn?

Its RecordingTransport rewrites every successful 200 response to disk, even if the content hasn't changed, leading to unnecessary diffs and version control noise.

Does GitHub Deploy Center support multiple PATs?

No—currently it stores only one Personal Access Token globally, making it impractical for developers managing personal, work, and client accounts.

Frequently Asked Questions

Why switch from Terraform to OpenTofu?

Organizations switch to avoid the BUSL license's competitive use restrictions and to ensure long-term supply chain security with a truly open-source, community-governed tool.

Can OpenTelemetry Collector run securely in locked-down Kubernetes clusters?

Yes, but it requires careful configuration of securityContext settings like runAsNonRoot, seccomp, and capabilities; a well-defined baseline is recommended for production.

Is the AWS Pricing Calculator MCP Server production-ready?

It's a prototype using browser automation, so it's useful for demos and internal estimates but may require maintenance if AWS changes the calculator UI.

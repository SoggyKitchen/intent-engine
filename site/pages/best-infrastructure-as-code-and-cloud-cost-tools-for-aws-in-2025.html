Frequently Asked Questions

Can OpenTofu replace Terraform in existing projects?

Yes. OpenTofu is a drop-in replacement for Terraform, supporting the same HCL syntax, providers, and state format. Migration requires minimal changes.

Why use browser automation for AWS pricing instead of APIs?

AWS does not offer a public API for the full Pricing Calculator. Browser automation via Playwright is currently the only way to programmatically generate accurate, shareable estimates across all 159 services.

Does cost-analysis-mcp-server support AWS ElastiCache drift detection?

No. It focuses on cost estimation from IaC, not runtime configuration drift. Drift detection for ElastiCache replication groups requires dedicated tooling or custom scripts.
